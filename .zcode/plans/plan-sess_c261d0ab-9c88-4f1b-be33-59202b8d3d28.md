# 为前后端添加 pm2dev / pm2prod 命令

## 现状
- pnpm monorepo:后端 `backend/`(Koa,CommonJS,`src/app.js` 自启动监听,`NODE_ENV` 决定加载 `.env.development`/`.env.production`,端口 9526);前端 `frontend/`(Vite 8,`"type": "module"`,dev 与 preview 均监听 9527,preview 自带 `/api/v1` → localhost:9526 代理)。
- 全仓库无任何 pm2 配置/依赖。

## 设计要点
- **pm2 不要求全局安装**:作为 devDependency 加入 frontend、backend 两个包(`pnpm --filter ./backend --filter ./frontend add -D pm2`),`pnpm run` 会自动把各自 `node_modules/.bin` 放进 PATH。
- **每个包两个 ecosystem 配置文件**(`.cjs` 后缀,因前端是 ESM 包):dev 与 prod 用**不同 pm2 进程名**(backend: `uac-api-dev`/`uac-api`;frontend: `eadaf-web-dev`/`eadaf-web`),互不干扰,watch 状态也不会串。
- **幂等**:`pm2 startOrReload` —— 未运行则启动,已运行则按新配置 reload,重复执行不会产生重复进程。
- **NODE_ENV 由 ecosystem 的 `env` 注入**,后端 dotenv 会自动加载对应 `.env.*`。

## 改动清单

### 1. 新建 4 个 ecosystem 配置
- `backend/ecosystem.dev.cjs`:`uac-api-dev`,script `src/app.js`,`watch: true` + `ignore_watch: ['node_modules', 'logs', '**/*.log']`,`env: { NODE_ENV: 'development' }`,`time: true`、`autorestart`、`max_memory_restart: '600M'`、`instances: 1`。
- `backend/ecosystem.prod.cjs`:`uac-api`,同上但 `watch: false`,`env: { NODE_ENV: 'production' }`。
- `frontend/ecosystem.dev.cjs`:`eadaf-web-dev`,script `node_modules/vite/bin/vite.js`(vite dev 自带 HMR,无需 pm2 watch),`env: { NODE_ENV: 'development' }`。
- `frontend/ecosystem.prod.cjs`:`eadaf-web`,script vite.js + `args: ['preview', '--host']`(托管已构建的 dist,`--host` 便于服务器上外部访问)。

### 2. 修改 3 个 package.json
- `backend/package.json` 与 `frontend/package.json` 各加:
  ```json
  "pm2dev": "pm2 startOrReload ecosystem.dev.cjs",
  "pm2prod": "pm2 startOrReload ecosystem.prod.cjs"
  ```
- 根 `package.json` 加(与现有 dev/start 风格一致):
  ```json
  "pm2dev": "pnpm --filter ./backend pm2dev && pnpm --filter ./frontend pm2dev",
  "pm2prod": "pnpm --filter ./backend pm2prod && pnpm --filter ./frontend pm2prod"
  ```
- 前端 `pm2prod` 不自动 build(已确认),需先自行 `pnpm --filter ./frontend build`。

### 3. 根 README 增加 pm2 使用说明
- 命令对照(根/各包)、4 个 pm2 进程名、常用操作:`pm2 list` / `pm2 logs <name>` / `pm2 stop|delete <name>`;说明前端 prod 依赖 dist 已构建、preview 代理指向 localhost:9526。

## 实现后验证
1. 先检查 9526/9527 端口占用(`lsof`),避免与正在跑的 dev 进程端口冲突。
2. `pnpm --filter ./backend pm2dev` → `pm2 list` 见 `uac-api-dev` online → `curl http://localhost:9526/api/v1/health` 返回 200。
3. `pnpm --filter ./frontend pm2dev` → `curl http://localhost:9527` 返回 200。
4. 再跑一次 backend pm2dev 验证幂等(reload,无重复进程)。
5. 验证 prod(backend + frontend,前端 dist 已存在):两个 `uac-api`/`eadaf-web` online 并可访问。
6. 验证完毕 `pm2 delete` 清理测试进程,保持环境干净。
